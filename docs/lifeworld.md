# 生活世界层

生活世界层给自主唤醒提供“为什么是现在”的现实入口。它不模拟人格，也不靠不断回放旧正文制造连续感；
它只保存少量可验证、可结束的生活结构。

## 种子选择

每次调度到点时，运行时只选择一个种子：

1. 原子领取最早到期的 `world_event`；
2. 若没有事件，生成包含本地日期与时段的 `free_window`；
3. 成功得到 `silent / trace / message` 后消费事件；
4. 被节律拦截、模型失败或意外异常时释放事件，留待重试。

事件领取带十五分钟租约。即使进程中途退出，过期领取也会恢复为等待状态。

宿主可以通过鉴权接口 `POST /world/events` 接入天气、日历、传感器或自定义事件。`summary` 应是一句
有限、事实性的描述；`evidence` 只包含理解这次事件所需的最小信息。

## 线头不是待办

线头代表一次醒来后仍然真心想继续的方向。它有来处、最近进展、下一次可以从哪里拿起，也可以自然结束。

- 同时最多保留五根开放线头；
- 同名开放线头不会重复创建；
- 重新浮现时间限制在 30 分钟到 7 天之间；
- 线头关闭后，尚未领取的旧提醒会被自动消费，不再打扰后续醒来。

这些限制是刻意的：系统应当拥有可以放下的兴趣，而不是替自己制造永远清不完的队列。

## 小作品

`artifact_create` 可以保存一次醒来真正完成的纯文本或 Markdown。作品有独立 ID、标题、媒体类型和时间，
不会因为模型在正文中声称“我写了”就自动产生。

当前内置作品工具支持纯文本与 Markdown。图片、音频、互动网页和作品发布可以由宿主应用通过工具注册表扩展；
具体分层方式见[整套融合指南](integration-guide.md)。

## 可见性

以下接口都需要管理员 Bearer Token：

| 接口 | 用途 |
|---|---|
| `POST /world/events` | 投递一个现在或未来可用的事件 |
| `GET /world/timeline` | 查看近期醒来结果 |
| `GET /world/threads` | 查看开放线头 |
| `GET /world/artifacts` | 查看作品索引 |

时间线不会反向改变轻连续性规则：下一次醒来仍只读取近期 `fact` 与一句临时余念，不会自动回放作品或完整正文。
